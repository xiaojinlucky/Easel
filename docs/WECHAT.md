# 微信公众号工作区

2026-09-10：桌面侧栏「公众号工作区」连接创作、账号证据读取、官方草稿箱与同行订阅。

## 自己的账号：绑定后读取与诊断

填写 AppID、AppSecret，点击「保存并连接账号」。后端校验授权，读取接口允许的最近最多 10 篇已发布文章以及昨日文章、阅读、用户统计；存在真实证据时，才通过现有 GPT 订阅对话生成定位与诊断。已有账号可点击「重新读取并诊断」。读取证据与缺失原因保存在 `.runtime/wechat-state.json`。

授权范围可能不包含全部历史群发文章或统计接口。没有证据不会请求模型；不能从少量阅读量推断限流，不能把受众假设写成已知事实。此阶段尚未绑定真实账号，未验证实际诊断准确度。跨平台自动读取与诊断尚未全部接通。

账号凭据保存在已忽略的 `skills/openclaw/skill-wechat-publisher/wechat-publisher.yaml`，不写入前端本地存储。账号或密钥改变会清除该账号的令牌缓存。

## 排版与草稿箱

无需凭据即可生成本地 Markdown / HTML 排版预览。正文在切页后保留。可以从内容库选择独立封面，插入正文图片；送草稿前验证全部本地图片并上传，复用现有 skill-wechat-publisher。外链图片需要先导入内容库。

「确认并送草稿箱」需要真实凭据，仅建立草稿，不自动群发。实际微信草稿上传和统计权限仍待用户接入验收。

## 同行更新

复用 MIT 许可的 WeRSS，桌面内点击「打开同行订阅管理」。服务地址为 `http://127.0.0.1:8090/`，管理员用户名 easel；密码通过工作区明确点击复制，不显示在日志或文档。服务在线并不代表微信扫码授权完成。

扫码后添加同行公众号，在 WeRSS 原生任务管理中设置每小时 cron `0 * * * *`。文章间隔为 60 秒，这是采集间隔，不是任务调度频率。当前没有授权账号、同行订阅或采集任务。FreshRSS 在同一 Docker 网络使用 `http://werss:8001` 的订阅地址；工作区「同步订阅到素材库」通过既有 FreshRSS 接口导入最近素材，并按来源 URL 去重。

## 持久化与维护

WeRSS 使用项目卷 `easel-postiz_werss-data`，加入现有备份卷范围；本地备份脚本也纳入公众号账号 YAML 与 wechat-state.json。本阶段未重新执行离线全量备份。

部署锁定镜像，来源和修补哈希见 `deploy/postiz/WERSS_UPSTREAM.json`、`WERSS_PATCH.json` 及镜像锁文件。三个只读源文件补丁移除启动环境转储及微信令牌日志/通知泄露。升级上游时需重新核验补丁兼容性。

修复和配置写入项目，重启可保留；外部平台接口和授权策略变化仍可能需要维护。不能承诺永久不失效。
