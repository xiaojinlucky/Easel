安装位置 <仓库根目录> · 上游 ZJU-REAL/Easel v0.1.1 · 网页 http://127.0.0.1:7870

先分清两套，别点错入口

现在请用这一套

文件夹 Easel-official
浏览器打开 http://127.0.0.1:7870
左侧只有：工作台、对话、技能库、内容库、账号、画像

里面叠了公众号工作区、引导页、Postiz 日历等二次开发，所以会觉得不会用

桌面上的「Easel 自媒体工作台」快捷方式打开的是二次开发版。看原版请用 7870，或运行 Easel-official\启动原版工作台.ps1。

原版每天怎么走

原版不是一堆分散工具，是一条线：先告诉它你是谁，再让它做内容，最后从内容库拿到成品去发。

flowchart LR A[画像] --> B[账号登录] B --> C[对话里说想法] C --> D[内容库看成品] D --> E[发布中心发出去] E --> F[工作台里看日历和数据]

第一次打开：按这 6 步

1
启动原版网页。看地址栏是不是 7870。侧栏左上角只写 Easel，没有额外「官方 API / 引导」长说明。
2
点左侧 画像。用向导填：你是谁、写给谁看、风格、常用平台、不做什么。没有画像，对话也能聊，但内容会很泛。
3
点左侧 账号。只登录你真要用的平台。小红书 / 抖音 / 快手 / 视频号 / 知乎 是扫码；B 站按它的提示；公众号在原版里也是「登录公众号后台」扫码。扫完关掉浏览器窗口即可，登录会留在本机。
4
回到 工作台。上面一排是：热点雷达选题库内容日历发布中心。先看热点，点「做成内容」会自动跳到对话。
5
在 对话 里用白话下指令，例如：「按我的画像，写一篇小红书，主题是研究生怎么第一次投论文」。左上角确认选中了你的画像。等它做完。
6
去 内容库 打开今天的项目文件夹，预览图、文案、视频。再到工作台的 发布中心 勾平台、附上封面或视频、先预检再发布。真正发出去前会再确认一次。

对话页如果提示「网关未连接」，先关掉二次开发桌面版，再到原版目录运行 .\.venv\Scripts\easel.exe gateway start，然后刷新 7870。两套不要同时抢 18789 这个对话口。

左侧六个入口分别干什么

入口你在这里做什么
工作台总览。热点、选题、日历、发布都收在这一页的顶栏，不用在侧栏找。
对话主战场。发现、策划、写作、做图做视频都对 Agent 说。它会自己选技能并把成品写入内容库。
技能库查「系统会什么」。日常不必从这里点，除非你想指定某一个技能。
内容库所有成品的文件夹。发布、下载、给下一篇当素材，都从这里拿。
账号平台登录状态。没登录的平台，发布中心发不出去。
画像人设记忆。换选题不用重写人设，换画像等于换一个账号大脑。

页面和文件怎么对应

你每天点的 ├── 工作台 → 热点 / 选题 / 日历 / 发布 ├── 对话 → Agent 执行技能，结果写入 outputs/ ├── 内容库 → outputs/ 里的项目文件夹 ├── 账号 → 各平台扫码，登录存在本机浏览器配置 └── 画像 → profiles/你的账号名/ 两套目录互不覆盖 ├── Easel-official/ 上游原版 v0.1.1（请用这个上手） │ ├── .venv/ 自己的 Python 环境 │ ├── outputs/ 原版自己的成品 │ └── 启动原版工作台.ps1 └── Easel/ 二次开发版（先冻结，别和原版混点）

原版故意没有的东西

这些是二次开发加的。在原版里找不到是正常的，不是你不会用：

  • 单独的「公众号工作区」长页（预览排版、WeRSS、AppID 表单堆在一页）
  • 授权引导三步卡片
  • Postiz 发布日历、FreshRSS 订阅这些外挂服务
  • 桌面托盘 / Electron 外壳

原版发公众号：账号页扫后台码 → 对话或发布中心交稿 → 进公众号草稿箱。不要去找二次开发里那张工作区。

常用命令（都在 Easel-official 里跑）

cd <仓库根目录>
.\.venv\Scripts\easel.exe doctor          # 看环境缺什么
.\启动原版工作台.ps1                      # 打开 http://127.0.0.1:7870
.\.venv\Scripts\easel.exe gateway start   # 对话网关（和二次开发版不要同时开）
.\.venv\Scripts\easel.exe ping            # 测网关和模型通不通
