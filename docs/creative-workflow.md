# 连续创作工作区

2026-10-15：第一批已在现役 `http://127.0.0.1:7871` 加载并完成桌面界面验收。范围按已确认的 **2 → 1 → 3**：全文检索与多素材引用、连续创作卡、同屏创作与局部修改。

## 怎么用

1. **素材库找素材**：搜索标题、正文、视频转写、图片文字和评论等已有字段。结果显示命中字段和片段。空格分隔的多个词须全部命中，可以分别落在不同字段；这是本地文本检索，不是语义搜索。
2. **勾选 1–5 条，开始创作**：切换搜索和筛选仍保留选择。每篇创作有固定身份，关联素材、专属对话、母稿、平台稿、卡片、历史版本及排期。新建时保存所选素材的文本快照。
3. **左边写稿，右边讨论**：对话自动带入这篇的素材、当前编辑文本和选中段落，沿用既有画像、`writing-style`、`meta-writing-core` 和原文锚点。助手给建议，由用户采纳；“用最近回复作为稿件”取回整条回复，仍需检查并删去不属于成稿的说明。
4. **只改一段**：在母稿中选择文字，填写替换建议，或从右侧取回建议，再点“只替换选中段落”。其余文字保留。替换可以立即撤销；继续手改后会关闭这次整体撤销，避免把新改的字一起抹掉。
5. **接着上次写**：未保存编辑缓存在当前浏览器；“保存版本”落到本机文件并保留旧版。“恢复为新版本”不会覆盖历史。需要在另一标签页接手时，关闭原编辑页后刷新。
6. **卡片与平台稿**：卡片沿用现有 Meta 模板；可重排整组，也可只改一张。发布中心保留独立平台稿，点“保存平台版本”写回这篇作品；“存草稿并排期”将具体版本关联到已有日历。平台真实发布仍由用户完成。

内容库的 Markdown、TXT、DOCX 文件可“另存为创作”。原文件只读；旧 `.doc` 不支持直接导入。`03-变现交付`、内部目录和工作区外文件不进入这一导入入口。

## 保护已有内容

| 对象 | 当前行为 |
|---|---|
| 飞书收藏快照 | 只读；检索不重写源数据。新创作留存所选字段，不随下一次素材刷新改变 |
| Word 手改稿与风格锚点 | 原件不覆盖；导入产生新稿，助手建议不自动修改长期风格 |
| 手改稿 | 本机草稿缓存 + 手动保存的新版本；服务器版本冲突会报错，不悄悄覆盖 |
| 同一创作的多标签页 | 同源浏览器编辑锁；其他页可看不可写。创作页与发布中心在同一标签中交接该锁 |
| 旧发布中心草稿 | 保留原存储项；每篇作品另用独立草稿，可通过“打开原独立草稿”返回 |
| 历史稿件和卡片 | 每次写入新路径；单张重做沿用其他卡片文件，旧图保留 |
| 内容库移动 | 同步关联路径；移动前检查元数据，写入失败会回退此次移动 |

未保存缓存属于当前浏览器。清除浏览器数据前应先“保存版本”；它不等于跨设备同步。当前已保存母稿、版本、来源和卡片在本机文件中，专属对话复用现有会话恢复机制。编辑锁要求支持 Web Locks 的本机浏览器；服务端仍会拒绝过期版本写入。
